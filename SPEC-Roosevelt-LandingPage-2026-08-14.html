First

What we are not changing

The structural decisions in this build are the reason we are adopting it over the current live page. None of the changes below should alter any of the following. If something in this spec appears to conflict with this list, the list wins — flag it back rather than working around it.

  • Section order, exactly as built. Existing sections do not move. The three new sections in this spec each carry a named insertion point — please use it rather than choosing your own, and flag it back if you think the placement is wrong
  • The hero keeps exactly one primary and one secondary CTA. Do not add a third inside the hero. The persistent sticky bar under P2 sits outside the hero and is the only exception
  • No CTA wording changes. "Watch the video", "Compare programmes", "Apply for Pro coaching", "Book Your Call" and "Join the Challenge" all stay as written
  • No price shown for Pro or Elite anywhere on the page
  • The VSL stays as the qualification gate ahead of the application
  • Application before price, call before sale
  • Three-tier layout with the 8-Week Challenge as the self-serve entry point
  • The four FAQ objection handlers and their order
  • The primary CTA must remain above 812px at 375px viewport width
Priority 0

Blocking — currently public on the staging URL

These are build completion rather than design. Item 1 unblocks items 2 to 4.

  1. Admin is not provisioned on the deployment P0

    /admin/login returns Admin credentials are not configured. Set ADMIN_USERNAME and ADMIN_PASSWORD in .env.local. The credentials work locally only, so nobody on our side can sign in to populate content. Please set these on the deployed environment and confirm the login works — everything below depends on it.

  2. Build instructions are rendering to the public page P0

    The VSL section displays Paste a YouTube URL in Admin → Home / Media → VSL video in place of the video. The testimonial block displays Replace these with your photos and quotes in Admin — Home / Media. Both are visible to any visitor.

  3. The VSL is empty P0

    The funnel is built on "watch the video to see if you qualify" and the application asks whether the visitor watched it. We will supply the video; please confirm the field accepts a standard YouTube URL and renders correctly once admin access is working.

  4. Placeholder testimonials are live P0

    "Alex", "Sam" and "Jordan" with placeholder quotes. We will supply five real named clients with before/after imagery from the live page. Please confirm the field structure — name, quote, category label, and whether an image slot exists per entry.

  5. A modal covers the hero on mobile load P0

    At 375×812 a testimonial overlay fires on page load and covers the headline, subheading and both CTAs. Please either remove it, or change the trigger to 50% scroll depth combined with exit intent, so the hero is never obscured on arrival.

Priority 1

Content to bring across

All assets available from the live programme page. We will supply final files.

  1. Logo lockup P1

    The header currently renders a plain text wordmark. Replace with the brand logo asset — /logo.svg on the live page. Centred in the header, as per the reference.

  2. Kane hero image — placement matters P1

    The page currently contains no imagery at all. Add the hero portrait, positioned below both CTAs rather than above them. On the live page it sits at 697px with the primary CTA at 472px, so it carries the visual weight without moving the button. Please follow the same order here: logo above, headline, CTAs, then image.

  3. WhatsApp Performance Coach section P1

    This is the most significant omission. The live page devotes a full section to it — four numbered steps plus a chat interface mockup showing a real coach message. It is the product's primary differentiator and there is currently no equivalent on the new build. We will supply the copy and the mockup spec.

    Insertion point: immediately after "The Gap" and before "How it works". The Gap states the problem — follow-through fails, not plans. The Coach is the mechanism that answers it, so it belongs directly beneath that claim and ahead of the process steps. No existing section moves; this one drops in between the two.

  4. Real client transformations P1

    Five named clients with before/after imagery, replacing the placeholder entries. Needs an image slot per testimonial if one does not already exist.

  5. Guarantee and trust line P1

    14-day money-back guarantee, plus a "secure checkout, cancel anytime" line beneath the CTA in the tier block. Neither currently appears.
